# CTF Writeups

A collection of Capture The Flag (CTF) challenges, solutions, and security lessons learned while improving practical penetration testing skills.

File created - 13th May, 2026 
## Platforms

### PicoCTF
Beginner-friendly challenges covering:
- Web exploitation
- Cryptography
- Reverse engineering
- Binary exploitation
- Forensics

### HackTheBox
Advanced penetration testing labs focused on:
- Enumeration
- Exploitation
- Privilege escalation
- Real-world attack paths

### Hacker101 CTF
Web security focused challenges covering:
- Authentication vulnerabilities
- Access control issues
- Injection flaws
- Application logic problems

### YesWeHack Dojo
Practical web security challenges designed around bug bounty style vulnerabilities.

### Intigriti Challenges
Realistic security challenges focused on vulnerability discovery and exploitation.

## Goals

- Improve offensive security methodology
- Practice vulnerability discovery
- Understand attacker mindset
- Document exploitation techniques
- Build practical security knowledge

## Structure

Each writeup contains:

- Challenge overview
- Reconnaissance
- Vulnerability analysis
- Exploitation process
- Root cause
- Mitigation
- Lessons learned
